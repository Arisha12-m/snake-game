# Snake Game in C++

A console-based Snake Game built in **C++** for Windows, developed as a group project for the **Programming Fundamentals** course at Fatima Jinnah Women University.

## Overview
A classic Snake game played in the console with colored graphics:
- Green head, cyan tail, red fruit, and yellow walls
- WASD controls, Pause/Resume, and Quit
- Invalid key detection with warning messages
- Play-again loop at game over

## Controls
| Key | Action |
|-----|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| P | Pause / Resume |
| Q | Quit |

## How to Run
This project uses Windows-specific headers (`windows.h`, `conio.h`), so it must be compiled and run on **Windows**.

1. Compile with a C++ compiler (e.g. MinGW or Visual Studio):
   ```
   g++ SnakeGame.cpp -o SnakeGame
   ```
2. Run the program:
   ```
   ./SnakeGame
   ```
